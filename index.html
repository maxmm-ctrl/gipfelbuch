Neue Tour aus GPX

Mehrere Touren gewählt
Verknüpfen: jede Datei bleibt eine eigene Zeile mit eigenem Gipfel, alle bekommen denselben Namen. Zusammenführen: eine Zeile für die ganze Tour, Höhenmeter, Distanz und Zeit werden addiert, »Tage« wird gesetzt.
Kopiert. So geht's weiter in Excel: Tourenbuch öffnen → Zelle in Spalte A der ersten freien Zeile direkt unter der Tabelle antippen → Einfügen. Alle kopierten Touren landen untereinander. Danach hier »Excel laden«, damit die Karte den neuen Stand zeigt.
