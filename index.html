Gipfelbuch einrichten

Deine Touren liegen privat in deinem GitHub-Repository. Damit diese Seite sie lesen und speichern darf, braucht sie einmal pro Gerät einen Zugangsschlüssel.

Schlüssel erstellen (einmalig, ca. 2 Minuten)

  1. Neuen Schlüssel auf GitHub erstellen ↗ (Fine-grained token)
  2. Token name: Gipfelbuch · Expiration: die längste Option
  3. Repository access: Only select repositories → gipfelbuch-daten
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token, den Schlüssel kopieren und unten einfügen.

Den Schlüssel kannst du für weitere Geräte im Passwort-Manager speichern. Er erlaubt nur den Zugriff auf dieses eine Repository.

Tipp fürs iPhone: Seite in Safari über »Teilen« → »Zum Home-Bildschirm« ablegen. Dann bleibt die Anmeldung dauerhaft erhalten.

Einstellungen & Daten

Darstellung

»Automatisch« folgt der Einstellung deines iPhones bzw. Computers. Die Wahl gilt für dieses Gerät.

Karten

»Zuletzt verwendete« öffnet jedes Gerät mit der Karte, die dort zuletzt gewählt war. Eine feste Startkarte gilt auf allen Geräten.

Beide sind für private Nutzung kostenlos. Wie man sie bekommt, steht im Kartenvergleich unter »Schlüssel«. Gespeichert werden sie in deinem privaten Daten-Repository und gelten auf allen Geräten.

Datenschutz

Diese Website ist öffentlich erreichbar, enthält aber keine Touren. Deine Daten liegen in deinem privaten Repository und werden nur mit deinem Schlüssel geladen. Für Gipfelvorschläge und die Gipfelsuche werden Koordinaten bzw. Suchbegriffe an OpenStreetMap geschickt.
